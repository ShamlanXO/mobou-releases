# Mobou for Mac

This repository holds the downloads and the update files of Mobou.
The source code is not in this repository.

## Download

Download `Mobou.dmg` from the latest release:
https://github.com/ShamlanXO/mobou-releases/releases/latest/download/Mobou.dmg

1. Open `Mobou.dmg`.
2. Drag Mobou to the Applications folder.
3. Open Mobou from the Applications folder.

Mobou needs macOS 12 or later and a Mac with an Apple chip (M1 or later).

## Safety

Each release is signed with the Apple Developer ID of the developer
(team `HJP9KPEHZU`) and notarized by Apple. Mobou updates itself only
with an update file that has the Mobou update signature.

More information: https://mobou.xyz
